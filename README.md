# DuyKR — Developer Portfolio

A responsive React + TypeScript portfolio built with Vite, Tailwind CSS, Motion, Lenis, and React Three Fiber.

## Run locally

```sh
npm install
npm run dev
```

Create a production build with `npm run build` and serve it with `npm run preview`.

## Personalize the content

- Update the name, email, social links, and location in `src/content.ts`.
- Replace the concept entries in `projects` with your own projects and real links. The current projects are clearly labeled concepts.
- Replace the editable education, project, learning, and milestone prompts in `timeline` with your own history.
- Edit the technology groups in `stack` to reflect the tools you use.
- Adjust the bio and role list in `src/App.tsx` to match your experience.

The abstract portrait artwork and the project visuals are CSS illustrations, so the portfolio does not depend on stock photography or external image assets.
